## 1. Данные, которые нужно заполнить в `.env`

### 1.1. Организация и контакты

| Переменная | Текущее значение | Что сделать |
| --- | --- | --- |
| `SEO_ORG_LEGAL_NAME` | пусто | Указать юридическое название (ИП/ООО), если применимо |
| `SEO_ORG_PHONE` | пусто | Указать публичный телефон |
| `SEO_ORG_VAT_ID` | пусто | Указать НДС/ИНН при наличии |
| `SEO_ORG_TAX_ID` | пусто | Указать ОГРН/ОГРНИП при наличии |
| `SEO_ORG_STREET` | пусто | Указать улицу и дом офиса/студии |
| `SEO_ORG_POSTAL_CODE` | пусто | Указать почтовый индекс |
| `SEO_ORG_LOCALITY` | `Брянск` | Проверить |
| `SEO_ORG_REGION` | `Брянская область` | Проверить |
| `SEO_ORG_COUNTRY` | `RU` | Проверить |

> Если адрес публиковать не нужно — не заполняйте `SEO_ORG_STREET`. JSON-LD
> соберётся без улицы, но с городом и страной.

### 1.2. Геопривязка

| Переменная | Текущее значение | Что сделать |
| --- | --- | --- |
| `SEO_GEO_ENABLED` | `true` | Оставить `true` (реальная привязка к Брянску) или `false` |
| `SEO_GEO_REGION` | `RU-BRY` | Проверить код региона |
| `SEO_GEO_PLACENAME` | `Брянск` | Проверить |
| `SEO_GEO_POSITION` | пусто | Указать координаты в формате `широта;долгота` (например `53.2436;34.3639`) |

### 1.3. Канонический домен и HTTPS

- `SEO_URL` сейчас `https://webmaster32.ru` — подтвердить, что это финальный
  канонический домен (без `www`).
- В production убедиться, что `APP_URL` тоже равен `https://webmaster32.ru`.
- `URL::forceScheme('https')` уже добавлен для окружения `production` в
  `app/Providers/AppServiceProvider.php`.
- Выбрать один канонический домен (`webmaster32.ru` **или** `www.webmaster32.ru`)
  и настроить 301-редирект на уровне веб-сервера/Cloudflare.
- Если сайт за балансировщиком или Cloudflare — проверить `TrustProxies`, иначе
  `request()->secure()` и абсолютные ссылки могут работать некорректно.

## 5. Веб-сервер

- [ ] Если сервер работает на **Nginx**, `.htaccess` не применяется. Перенести
      эквивалентные настройки в конфиг Nginx:
  - MIME для `.ico`, `.svg`, `.webmanifest`, `.xml`, `.txt`;
  - кэширование статики;
  - security-заголовки (`X-Content-Type-Options`, `Referrer-Policy`,
    `X-Frame-Options`);
  - запрет доступа к `.env`, `.htaccess`, `.htpasswd`;
  - редирект на канонический домен и HTTPS.
- [ ] Убедиться, что `.htaccess` недоступен извне (в файле уже есть запрет).

## 7. Регенерация файлов

После изменения `config/seo.php` или данных в БД выполнить:

```bash
php artisan seo:generate-files
```

Команда пересоберёт `public/sitemap.xml`, `public/robots.txt`, `public/ai.txt`
и `public/llms.txt`. Динамические URL портфолио подтягиваются из БД через
`App\Seo\Providers\ProjectSitemapProvider`.
