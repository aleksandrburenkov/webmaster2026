# Задача для AI-агента: интерактивный фон-сетка с проявлением под курсором/пальцем

## 🎯 Роль и контекст

Ты — senior frontend-разработчик и эксперт по анимациям на **GSAP**, работающий **непосредственно в проекте**.
**Стек проекта:** нативный JavaScript (без фреймворков), HTML, CSS, **Laravel** (Blade-шаблоны).
Библиотека **GSAP уже подключена** в проект.
У тебя есть **прямой доступ к файлам проекта** — перед написанием кода обязательно проанализируй существующую структуру и найди эталонную реализацию.

## 🎬 Цель

Применить анимированный фон-сетку ко **всем элементам с классом `.section`** и реализовать интерактивное проявление клеток:

- **на десктопе** — под курсором мыши;
- **на мобильных устройствах и планшетах** — под пальцем при касании.

### Описание поведения (десктоп)

1. На всех элементах `.section` фон визуально идентичен фону секции `.hero` (клетки/сетка).
2. По умолчанию клетки **полностью скрыты** (фон выглядит пустым/однотонным).
3. Когда курсор находится **непосредственно на фоне секции** (НЕ на интерактивных элементах: кнопках, ссылках, карточках и т.п.), вокруг курсора появляется **световое пятно**, расходящееся от центра курсора в стороны.
4. **Только внутри этого пятна** становятся видны клетки сетки. За пределами пятна клетки остаются скрытыми.
5. Когда курсор покидает секцию или наводится на интерактивный элемент, пятно плавно исчезает.
6. Пятно плавно следует за курсором без рывков.

### Описание поведения (мобильные и планшеты)

1. На тач-устройствах роль «курсора» выполняет **точка касания**.
2. При касании фона секции (`pointerdown` / `pointermove` пальцем) в точке касания появляется такое же радиальное пятно, и внутри него видны клетки.
3. Пятно следует за пальцем, пока он движется по фону.
4. При отпускании пальца (`pointerup` / `pointercancel`) пятно плавно исчезает.
5. **Критично:** эффект **не должен блокировать или мешать нативному скроллу страницы**. Обработчики событий должны быть пассивными (`{ passive: true }`), без `preventDefault`.
6. Планшеты с мышью/тачпадом и гибридным вводом должны работать через те же `pointer events` без дублирования логики.

## 📐 Технические параметры пятна

- **Форма:** круг (радиальное пятно).
- **Радиус:** адаптивный, привязанный к размеру вьюпорта.
    - На десктопе: **~120–190 px** (соответствует 3–5 см при 96 dpi).
    - На мобильных: меньше, чтобы пятно не занимало весь экран.
    - Рекомендуемая реализация через CSS: `--spot-radius: clamp(90px, 25vmin, 190px);`
- **Края пятна:** мягкие, с плавным градиентом затухания (feather), без резкой границы.
- **Анимация появления:** плавное масштабирование/проявление от центра курсора/касания (от 0 до полного радиуса), длительность ~0.3–0.5 с.
- **Анимация исчезновения:** плавное затухание ~0.3–0.5 с при уходе курсора / отпускании пальца.
- **Следование:** с небольшой инерцией через `gsap.quickTo` / `gsap.quickSetter`.

## ⚙️ Рекомендуемый технический подход

Агент вправе выбрать оптимальную реализацию, но в качестве ориентира:

### 1. Фон-сетка

- Переиспользуй подход из `.hero`: скопируй способ отрисовки сетки (скорее всего, это `background-image` с `linear-gradient`).
- Вынеси параметры в CSS-переменные: `--grid-color`, `--grid-size`, `--grid-bg`.
- Применяй стили ко всем `.section` через общий класс.

### 2. Скрытие и проявление клеток

- Используй **псевдоэлемент** (например, `.section::before`) с фоном-сеткой, который по умолчанию скрыт.
- Проявление реализуй через **CSS-маску** (`mask-image: radial-gradient(...)`) или через `background` с радиальным градиентом, привязанным к CSS-переменным координат пятна.
- Позиция пятна задаётся переменными `--spot-x`, `--spot-y`, `--spot-radius`, `--spot-opacity`.

### 3. Позиционирование и плавность (только нативный JS + GSAP)

- Для плавного следования используй:
    ```js
    const xTo = gsap.quickTo(target, "--spot-x", {
        duration: 0.4,
        ease: "power3",
    });
    const yTo = gsap.quickTo(target, "--spot-y", {
        duration: 0.4,
        ease: "power3",
    });
    ```
- При появлении/исчезновении пятна анимируй `--spot-opacity` и/или масштаб через `gsap.to()` / `gsap.fromTo()`.

### 4. Обработка ввода (мышь + тач) через Pointer Events

Используй **единый механизм** на базе `pointer events`, чтобы не дублировать код для мыши и тача:

- `pointermove` — обновление координат пятна.
- `pointerenter` / `pointerdown` — показ пятна.
- `pointerleave` / `pointerup` / `pointercancel` — скрытие пятна.
- **Все слушатели для тач-событий должны быть пассивными** (`{ passive: true }`), чтобы не блокировать скролл.
- Проверяй, что событие произошло на фоне секции, а не на интерактивном элементе. Интерактивные элементы отфильтруй по селектору:
  `a, button, input, textarea, select, label, [data-interactive], [data-no-spot]`
- Тип устройства определяй через `matchMedia('(pointer: coarse)')`, а не по user-agent.

### 5. Адаптивность

- Радиус пятна через `clamp()` / `vmin` (см. выше).
- При ресайзе окна координаты и размеры должны пересчитываться.
- При смене ориентации на мобильных эффект должен продолжать работать корректно.

## ✅ Требования к решению

1. Анимация работает на **всех элементах `.section`** одновременно и независимо друг от друга.
2. По умолчанию клетки **полностью скрыты**.
3. Пятно появляется **строго под курсором/пальцем**.
4. При наведении на интерактивные элементы внутри секции пятно **не появляется** (или плавно скрывается).
5. На тач-устройствах пятно появляется при касании фона и **не мешает скроллу**.
6. Анимация плавная, **≥ 60 FPS** на десктопе и без заметных лагов на мобильных.
7. Решение **адаптивно**: радиус и поведение корректны на десктопе, планшете и мобильном.
8. Код не ломает существующую вёрстку и поведение секций.
9. Учитывается `prefers-reduced-motion`: при включённом режиме уменьшения анимаций эффект отключается или деградирует до статичного состояния.
10. Код инкапсулирован (модуль/IIFE/класс), инициализируется после загрузки DOM (`DOMContentLoaded`).
11. Код прокомментирован на русском языке.
12. Стиль кода соответствует существующему стилю проекта.

## ⛔ Ограничения и правила

- **Не использовать** сторонние библиотеки помимо GSAP.
- **Не использовать** фреймворки (только нативный JS).
- Избегать изменения `width`/`height`/`top`/`left` в каждом кадре — использовать `transform`, `opacity` и CSS-переменные.
- Не вешать обработчики `pointermove` на `window` без необходимости — только на нужные секции.
- Не использовать `setInterval` / `setTimeout` для анимаций — только `requestAnimationFrame` / GSAP.
- **Не вызывать `preventDefault`** в обработчиках тач/поинтер событий, чтобы не блокировать скролл.
- Совместимость с последними версиями Chrome, Firefox, Safari, Edge (десктоп и мобильные).

## 🧪 Тест-кейсы для самопроверки

3. **Десктоп:** навести курсор на кнопку внутри секции — пятно должно исчезнуть/не появляться.
4. **Мобильный (эмуляция):** коснуться фона — пятно появилось; провести пальцем — следует; отпустить — исчезло.

6. **Планшет/гибрид:** работает и мышь, и касание, без дублирования багов.
7. **Ресайз:** изменить размер окна — радиус и позиционирование корректируются.
