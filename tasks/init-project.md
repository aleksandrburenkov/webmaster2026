### 2. ТЕХНИЧЕСКИЙ СТЭК И ОГРАНИЧЕНИЯ
* **Backend:** Laravel 11/12 (разворачивается локально на Open Server / OSPanel).
* **Admin-панель:** Filament PHP v3 (управление кейсами, ценами, настройками).
* **Frontend:** Laravel Blade шаблоны, нативный CSS (в папке `public/css/`), чистый Vanilla JS ES6-модули (в папке `public/js/`).
* **Критическое ограничение:** СТРОГО БЕЗ использования сборщика Vite, npm-пакетов на фронтенде, а также без JS-перехватчиков нативной физики скролла (запрещено использовать Lenis, Locomotive Scroll и аналоги).
* **Библиотеки (подключение через CDN):** Tailwind CSS, базовое ядро GSAP 3 + ScrollTrigger (GSAP допускается только для магнитного взаимодействия, сложной курсорной интерполяции и редких эффектов, которые тяжелее реализуются нативно).
* **База анимации:** Основные scroll-эффекты, reveal, progress-индикация и горизонтальный скролл должны быть реализованы на базе современных **нативных CSS Scroll-Driven Animations**, View Transitions API и CSS `@property`.

### 3. КРЕАТИВНЫЕ ФУНКЦИИ И СТРУКТУРА

1. **Интеллектуальный кастомный Progress Rail:**
   * Стандартный скроллбар браузера полностью скрывается через нативный CSS.
   * С правой стороны экрана создается минималистичный кастомный индикатор прокрутки.
   * При быстром нативном скролле бегунок за счет CSS/JS физически эластично растягивается в длину (эффект пластичности) и усиливает свечение.
   * *Section-Aware Logic:* JS + ScrollTrigger отслеживают положение страницы. Каждая секция имеет атрибут `data-scroll-color`. При входе в секцию ползунок ПЛАВНО меняет свой цвет под палитру текущего экрана. На touch-устройствах индикатор скрывается.
2. **Hero / Opening:** Ограничен одним запоминающимся интерактивным жестом (например, плавное проявление света вокруг ключевого слова или движение типографического слоя за курсором). Никаких обязательных театральных прелоадеров, блокирующих пользователя, если не идет реальная загрузка медиа-ресурсов.
3. **Ультра-интерактивное Портфолио (Selected Work):**
   * Горизонтальное раскрытие кейсов через sticky-секцию и CSS Scroll-Driven Animation.
   * Механика Hover: При наведении на карточку кейса, цвет кастомного progress rail мгновенно меняется на фирменный цвет проекта (`data-scroll-color`). При этом в ограниченной атмосферной области карточки через пошаговый Stagger премиально проявляются скрытые плашки с метаданными из CMS Filament: *Суть проекта, Бюджет (в ₽) и Сроки реализации (в днях)*. Контраст по стандартам WCAG должен строго сохраняться.
4. **Управление темами:** Бесшовное переключение Светлой (базовая: молочно-белый, айвори, графитовый текст) и Темной темы (глубокий обсидиан, неоновые микро-акценты) с использованием View Transitions API. Ползунок прогресса также инвертирует базовые цвета.
5. **Exit-Intent (Умный маркетинг):** Опциональный поп-ап "Уникальное предложение", срабатывающий по событию `mouseleave` (увод курсора к закрытию вкладки) строго один раз за сессию через проверку нативных Cookies / sessionStorage. Полностью отключен на touch-устройствах и при клавиатурной навигации.
