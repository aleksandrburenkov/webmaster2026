# Техническое задание: Рефакторинг анимаций и удаление горизонтального скролла

**Цель:** Полностью убрать механику горизонтального перемещения карточек в блоке портфолио. Заменить её на классическое, плавное и гармоничное проявление элементов (текста, карточек и графики) при стандартной вертикальной прокрутке страницы.

---

## 1. Изменения в Blade-шаблоне (`index.blade.php`)

- **Секция `#work` (Портфолио):**
    - Полностью удалить внешние обёртки, отвечающие за фиксацию экрана и трек: `.portfolio-track-wrapper` и `.portfolio-sticky`.
    - Выстроить карточки проектов в стандартную вертикальную сетку. Использовать существующий класс `.grid-3` или стандартную сетку (например, `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-8`).
    - Для карточек проектов применить класс плавного проявления (например, `.reveal-smooth`).
- **Контентные блоки (Текст и Заголовки):**
    - Заменить резкие анимации на новые классы плавного проявления (`.reveal-text` для описаний и `.reveal-smooth` для заголовков и карточек).

---

## 2. Изменения в файле стилей (`CSS`)

### А. Удаление старой механики

- Полностью удалить анимацию `@keyframes portfolio-scroll`.
- Удалить неиспользуемые стили для классов: `.portfolio-track-wrapper`, `.portfolio-sticky`, `.portfolio-track`, `.portfolio-scroll-driven`.
- Очистить или упростить блок `@media (prefers-reduced-motion: reduce)`, убрав из него сбросы для горизонтального трека.

### Б. Внедрение новых гармоничных анимаций (Scroll-Driven)

Добавить новые, легкие эффекты появления элементов, которые работают на нативном CSS от вертикального скролла:

```css
/* Плавное всплытие элементов (для заголовков и карточек) */
.reveal-smooth {
    opacity: 0;
    transform: translateY(30px) scale(0.98);
    animation: reveal-in-view linear forwards;
    animation-timeline: view();
    animation-range: entry 10% entry 75%;
}

@keyframes reveal-in-view {
    to {
        opacity: 1;
        transform: translateY(0) scale(1);
    }
}

/* Мягкое проявление текста (из легкого размытия) */
.reveal-text {
    opacity: 0;
    filter: blur(4px);
    animation: reveal-text-in linear forwards;
    animation-timeline: view();
    animation-range: entry 15% entry 65%;
}

@keyframes reveal-text-in {
    to {
        opacity: 1;
        filter: blur(0);
    }
}

/* Плавное появление графики или блоков сбоку (слева направо) */
.reveal-aside-left {
    opacity: 0;
    transform: translateX(-40px);
    animation: reveal-from-left linear forwards;
    animation-timeline: view();
    animation-range: entry 5% entry 60%;
}

@keyframes reveal-from-left {
    to {
        opacity: 1;
        transform: translateX(0);
    }
}
```

---

## 3. Требования к результату

1. **Никакого горизонтального движения:** Сайт должен прокручиваться только строго вниз. Экран не должен «прилипать» на блоке портфолио.
2. **Плавность:** Карточки проектов должны аккуратно «всплывать» снизу по мере того, как пользователь докручивает до них страницу.
3. **Производительность:** Анимации должны оставаться на чистом CSS (`animation-timeline: view()`), чтобы не нагружать процессор смартфона или компьютера.
4. **Адаптивность:** Сетка карточек должна корректно перестраиваться с 3 колонок на десктопе в 1 колонку на мобильных устройствах.
