# Финальные адаптивные стили интеграции ИИ-анимации

Добавьте этот блок стилей в конец вашего файла `hero.css`. Код использует существующую у вас архитектуру слоев (`z-index`) и гармонично сосуществует с CSS-анимациями `slide-up`.

---

## 🎨 Интеграционные CSS стили (`hero.css`)

```css
/* ==========================================================================
   1. Корректировка существующих классов (Корректное разделение пространства)
   ========================================================================== */

/* Ограничиваем ширину текста на десктопах, чтобы освободить место для 3D справа */
@media screen and (min-width: 993px) {
    .hero-content {
        max-width: 50% !important; /* Перебиваем дефолтные 800px для десктопов */
    }
}

/* ==========================================================================
   2. Контейнер для SVG-анимации DeepSeek
   ========================================================================== */
.hero-ai-graphics {
    position: absolute;
    right: 0;
    top: 0;
    width: 50%;
    height: 100%;
    display: flex;
    align-items: center;
    justify-content: center;
    pointer-events: none; /* Пропускает клики к элементам интерфейса */
    z-index: 2; /* Выше подложки, но не мешает скролл-индикатору */

    /* Элегантное появление вместе с общим интро секции */
    opacity: 0;
    transform: translateX(30px);
    animation: fade-in-vector 1200ms 600ms cubic-bezier(0.4, 0, 0.2, 1) forwards;
}

#deepseek-vector-core {
    width: 90%;
    height: 75%;
    max-width: 600px;
    max-height: 600px;
    pointer-events: auto; /* Возвращает интерактивность мыши на узлы */
}

/* ==========================================================================
   3. Адаптивные медиа-запросы (Медиа-точки под ваш проект)
   ========================================================================== */

/* 💻 Оптимизация под экраны ноутбуков (MacBook 13", стандартные Full HD мониторы) */
@media screen and (max-width: 1400px) {
    #deepseek-vector-core {
        max-width: 500px;
        max-height: 500px;
    }
}

/* 📐 Планшеты (Плавный увод абстракции на задний план, под текст) */
@media screen and (max-width: 992px) {
    .hero-content {
        max-width: 100% !important; /* Текст снова встает на всю ширину */
    }

    .hero-ai-graphics {
        width: 100%; /* Контейнер растягивается фоном под весь контент */
        z-index: 0; /* Смещаем за текстовый блок (.hero-content имеет z-index: 1) */
        opacity: 0.25; /* Сильно приглушаем, чтобы не мешать читаемости текста */
        justify-content: flex-end; /* Центрируем графическое ядро ближе к правому краю */
        padding-right: 2%;
        transform: translateX(0);
        animation: fade-in-vector-tablet 1200ms 600ms
            cubic-bezier(0.4, 0, 0.2, 1) forwards;
    }

    #deepseek-vector-core {
        max-width: 450px;
        max-height: 450px;
    }
}

/* 📱 Смартфоны (Полное отключение векторов для экономии ресурсов FPS/процессора) */
@media screen and (max-width: 768px) {
    .hero-ai-graphics {
        display: none !important;
    }
}

/* ==========================================================================
   4. Вспомогательные Keyframes для интро-анимации вектора
   ========================================================================== */
@keyframes fade-in-vector {
    0% {
        opacity: 0;
        transform: translateX(30px);
    }
    100% {
        opacity: 1;
        transform: translateX(0);
    }
}

@keyframes fade-in-vector-tablet {
    0% {
        opacity: 0;
    }
    100% {
        opacity: 0.25; /* Синхронизировано с opacity планшетного режима */
    }
}
```
