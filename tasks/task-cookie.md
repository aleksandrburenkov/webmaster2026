# Задача: Реализация уведомления об использовании Cookie (Cookie Consent)

## Контекст

Проект на базе Laravel. Необходимо разработать и внедрить плашку согласия на использование файлов cookie.

## Требования к функционалу

1. **Логика показа:** Плашка должна отображаться только тем пользователям, которые еще не приняли условия.
2. **Анимация:** Плавное появление (мягкий переход) после загрузки страницы с дополнительной задержкой ровно в 0.5 секунды.
3. **Срок действия:** При подтверждении пользователю устанавливается куки со сроком жизни ровно 30 дней.
4. **Дизайн:** Плашка должна использовать текущие цвета сайта (опираться на существующие CSS-переменные или глобальные стили проекта).
5. **Текст:** Стандартный юридический текст (пример: "Мы используем файлы cookie для улучшения работы сайта. Продолжая использовать сайт, вы соглашаетесь с политикой конфиденциальности.") и кнопка "Принять".
6. **Адаптивность:** Баннер корректно отображается во всех популярных разрешениях (от 320px до 1024px) как в портретной, так и в альбомной ориентации..

## Пошаговый план реализации

### 1. Архитектура и шаблонизация (Blade)

- Создай компонент `resources/views/components/cookie-consent.blade.php`.
- Подключи компонент в главном шаблоне (обычно `resources/views/layouts/app.blade.php`) перед закрывающим тегом `</body>`.
- Блок должен быть позиционирован через `fixed` (например, внизу экрана или в нижней части экрана по центру), чтобы не смещать контент.
- По умолчанию плашка должна быть скрыта (например, `opacity-0` и `translate-y-4` или `display: none`), чтобы избежать мигания (FOUC).

### 2. Стилизация

- Настрой цвета фона, текста и кнопки, используя палитру проекта.
- Обеспечь адаптивность: на мобильных устройствах плашка должна занимать всю ширину экрана или аккуратно центрироваться.

### 3. Логика на JavaScript (Vanilla JS)

Добавь скрипт (согласно архитектуре приложения):

- **Проверка:** При инициализации проверяй наличие куки `cookie_consent=true`.
- **Задержка и анимация:** Если куки нет, повесь обработчик на событие `window.onload`. Внутри запусти `setTimeout` на 500 мс. По истечении таймера добавь плашке классы видимости (например, `opacity-100`, `translate-y-0`) с использованием CSS `transition`.
- **Принятие:** При клике на кнопку "Принять":
    - Создай куки: `document.cookie = "cookie_consent=true; path=/; max-age=" + (30 * 24 * 60 * 60);`
    - Плавно скрой плашку (убери классы видимости).
    - Удали плашку из DOM после завершения анимации (через 300-500 мс).

## Критерии приемки (Acceptance Criteria)

- [ ] Плашка появляется только при отсутствии куки `cookie_consent`.
- [ ] После нажатия "Принять" плашка исчезает и не появляется при перезагрузке страницы в течение 3 дней.
- [ ] Анимация появления плавная, стартует после загрузки страницы + 0.5 секунды.
- [ ] Дизайн плашки соответствует цветовой гамме сайта.
- [ ] Верстка не ломается на мобильных устройствах.
- [ ] Реализация не использует тяжелые сторонние библиотеки (только нативный JS/CSS).
