````markdown
## Приоритет реализации

Выбери один из вариантов в зависимости от анализа проекта.

### Вариант 1 — если уже есть механизм статических страниц

Используй его.

Например:

- уже есть `PageController`
- уже есть модель `Page`
- уже есть Blade-шаблоны для статических страниц
- уже есть маршруты вида `/terms`, `/about`
- уже есть localization routes

В этом случае просто добавь две страницы по существующему паттерну.

---

### Вариант 2 — если проект обычный Laravel + Blade

Создай минимальную публичную реализацию:

- маршруты в `routes/web.php`
- контроллер или invokable-контроллер
- Blade-вьюшки
- подключение к существующему layout

---

### Вариант 3 — если используется Livewire full-page component

Если в проекте уже используются Livewire-страницы, можно добавить страницы как Livewire full-page components.

Но если есть более простой существующий Blade-паттерн, используй его.

---

### Вариант 4 — если используется Inertia

Если проект на Inertia:

- добавить маршруты
- создать страницы во фронтенд-директории проекта
- возвращать через `Inertia::render()`

Используй текущий стиль Inertia-страниц.

---

### Вариант 5 — если страницы должны быть внутри Filament

Если из структуры проекта ясно, что страницы должны быть доступны именно в Filament-панели:

- создать кастомные Filament Pages
- использовать существующую панель
- добавить маршруты внутри панели, если это нужно
- добавить навигацию, если это уместно

Но если страницы нужны для публичного сайта, не прячь их за авторизацией.

## Требуемые маршруты

Добавь публичные маршруты:

```php
Route::get('/privacy-policy', ...)->name('privacy-policy');
Route::get('/offer', ...)->name('offer');
```
````

Если в проекте есть локаль-префиксы, добавь маршруты в существующую localization-группу.

Пример с локалями, если они есть:

```php
Route::group(['prefix' => '{locale}', ...], function () {
    Route::get('/privacy-policy', ...)->name('privacy-policy');
    Route::get('/offer', ...)->name('offer');
});
```

Если проект использует префикс `/ru`, `/en` и т.п., следуй существующему паттерну.

Методы:


Если в проекте используются invokable-контроллеры, можно создать:

```text

```

Выбери минимальный и наиболее совместимый вариант.
