# Задача: Кнопка «Наверх» (Scroll to Top)

## Описание

Реализовать кнопку возврата наверх. Расположение — **правый нижний угол** экрана. Визуальный стиль должен соответствовать существующей тематике сайта (цвета, скругления, тени — взять из текущих дизайн-токенов / стилей проекта).

## Ограничения

- Только нативный JavaScript. Без библиотек, без фреймворков.
- **Запрещено** использовать `behavior: 'smooth'` и `window.scrollTo({ behavior: 'smooth' })`.
- Анимация скролла — через `requestAnimationFrame` + математическая easing-функция (например, `easeInOutQuad`).
- Анимация не должна зависеть от ОС (Windows, macOS, Linux) и не должна блокироваться системными настройками.
- `scroll`-listener вызывать с `{ passive: true }`.
- Использовать методику написания скрипта такую же как реализованы остальнве через import.
- Не выдумывать сложных скриптов — брать простые, проверенные паттерны.

## Адаптивность

- Показывать кнопку только на **десктопе и планшете** (ширина ≥ 768px).
- На мобильных устройствах (ширина < 768px) кнопка **полностью скрыта** через CSS `display: none` внутри `@media`.

## Поведение

1. Кнопка изначально скрыта.
2. Появляется (класс `is-visible`) проверить, если такой класс существует добавить какой нибудь префикс или постфикс, когда `window.scrollY` превышает порог (400px).
3. Исчезает при возврате выше порога.
4. По клику — плавный скролл наверх (длительность ~600мс) через `requestAnimationFrame` и easing-функцию.
5. Появление/исчезновение кнопки — через `opacity` + `visibility` в CSS (transition).

## Что нужно сделать

1. Найти основной HTML-файл проекта. Добавить элемент `<button class="scroll-to-top" id="scrollToTop" aria-label="Наверх">` перед закрывающим `</body>`.
2. Найти основной CSS-файл проекта. Добавить стили кнопки, адаптировав цвета и скругления под существующую тему сайта.
3. Создать файл `scroll-to-top.js` (или добавить блок в существующий скрипт проекта) с логикой показа и анимации.
4. Подключить скрипт в HTML с атрибутом `defer`.
5. Убедиться, что на экранах < 768px кнопка не отображается.

## Критерии приёмки

- [ ] Кнопка видна на десктопе и планшете, скрыта на мобильных.
- [ ] Появляется после скролла 400px вниз.
- [ ] По клику плавно скроллит наверх через `requestAnimationFrame` + easing.
- [ ] `behavior: 'smooth'` нигде не используется.
- [ ] Нет зависимостей от сторонних библиотек.
- [ ] Стиль кнопки соответствует общему дизайну сайта.
- [ ] Код не ломает существующую функциональность.
